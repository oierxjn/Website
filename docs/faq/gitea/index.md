# Gitea 答疑平台使用指南

## 进入条件

课程的答疑主要在 [同济高程答疑平台](http://10.80.42.185/QA/) 上各个仓库的 Issue 区进行。网站仅限同济大学校园网或同济 VPN 访问。


## 注册与登录

账号注册目前由管理员管理，没有额外的注册入口。有问题请[联系团队](/contact.md)

打开 [同济高程答疑平台](http://10.80.42.185/QA/)

![同济高程答疑平台首页](MainPage.png)

点击右上角 `登录`

![同济高程答疑平台登录页面](GiteaLoginPage.png)

选择 `使用「高程统一身份认证」登录` 

![同济高程答疑平台统一身份认证登录](OIDCPage.png)

在这个界面填入你的**高程身份认证信息**。用户名与密码与`文档作业网站`/`编程作业网站`一致。填写完毕后点击 `登录并继续`。

![同济高程答疑平台仪表盘](GiteaDashboard.png)


## 组织结构

平台上的内容按两层结构组织：

+ **组织（Organization）**：按年份划分，对应每一届课程
+ **仓库（Repository）**：按知识模块划分，对应课程的不同章节/主题

## 搜索已有的 Issue

首先需要进入对应的仓库页面。

![同济高程答疑平台仓库页面](DashboardRepo.png)

提问之前，先在仓库的 Issue 列表中搜索是否已有相同或相似的问题。

![仓库 Issue 搜索](SearchIssue.png)

如果你找到了相似的 Issue，点击对应 Issue 进入即可查看相关解答。

![Issue 搜索结果](SearchIssueResult.png)

如果没有找到相关 Issue，可以参考下一个段落，选择发布一个新的 Issue。

## 发布新 Issue

::: warning
发布 Issue 前，请再次确认你的问题符合 [学会提问](/ask-question/) 中的规范。并且，提出已经存在的相同或相似的问题很有可能被判定为**重复 Issue**，将很有可能被关闭，**不会**得到回答。
:::

当你需要开一个新的 Issue 时，点击`创建 Issue`的按钮。

![创建新 Issue](CreateIssue.png)

进入之后自行判断选择合适的分类（若没有则跳过这条）。

![Issue 模板分类](IssueFilter.png)

进入之后根据已有的模板填写尽量详细的信息。

![填写 Issue 模板](FillIssueTemplate.png)

信息填写完成之后点击页面最下方的 `创建 Issue` 按钮。

![创建 Issue 按钮](CreateIssueButton.png)

这样你的 Issue 就成功创建了，其他同学和助教可以在该 Issue 下进行提问和回复。

## 评论回复

当你需要在已有的 Issue 中进行继续提问或回复时，可以在该 Issue 页面底部的评论框中输入你的内容，然后点击 `发表评论` 按钮。

![Issue 评论](IssueComment.png)

然后你就可以等待其他同学或助教的回复。

## 关闭/重新打开 Issue

::: warning
有权限关闭/重新打开 Issue 的用户仅包括提问者和具有相应权限的助教/老师。
:::

当这个Issue 提出的问题得到解决后，建议你选择关闭该 Issue。关闭 Issue 的操作通常由提问者完成，表示问题已经得到满意的解答。

在 Issue 页面底部的评论框下方，找到 `关闭 Issue` 按钮，点击即可关闭该 Issue。

![关闭 Issue 按钮](CloseIssue.png)

当然，如果你的 Issue 重复或者完全无意义/不符合规范，它可能会被助教/老师直接关闭。~~比如问今天吃什么。~~

当你觉得你的 Issue 未得到解决却被关闭，你可以选择重新打开这个 Issue。同样在 Issue 页面底部的评论框下方，找到 `重新打开` 按钮，点击即可重新打开该 Issue。

![重新打开 Issue 按钮](ReopenIssue.png)

## Gitea 作为答疑平台的意义

> Gitea 是一个轻量级的 DevOps 平台软件。从开发计划到产品成型的整个软件生命周期，他都能够高效而轻松的帮助团队和开发者。包括 Git 托管、代码审查、团队协作、软件包注册和 CI/CD。它与 GitHub、Bitbucket 和 GitLab 等比较类似。 Gitea 最初是从 Gogs 分支而来，几乎所有代码都已更改。Gitea的首要目标是创建一个极易安装，运行非常快速，安装和使用体验良好 的自建 Git 服务。

如你所见，Gitea 提供了完整的基础的 Issue 管理功能，便于课程中问题的答疑和追踪。

当然，目前只使用其 Issue 功能，其他功能的利用正在规划中。

相比群聊，使用 Issue 答疑的好处是：

+ 可以用 Issue 模板规范化提问，确保提供必要的信息
+ 问题与回答被完整保留，不会因为群消息刷屏而丢失
+ 可以方便地追踪问题的解决进度
+ 其他同学遇到相同问题时可以搜索到已有的解答，避免重复提问/解答浪费时间
+ 按知识模块分类管理，便于针对性地查找
+ 可以挑选出有价值的问题，供所有人方便地参考
